# 📸 App Store Screenshot Requirements & Guide

## iOS App Store Screenshot Requirements

### Required Device Sizes
1. **iPhone 6.7"** (iPhone 14 Pro Max, 15 Pro Max)
   - Resolution: 1290 x 2796 pixels
   - Required: 3-10 screenshots

2. **iPhone 6.5"** (iPhone 14 Plus, 15 Plus)
   - Resolution: 1242 x 2688 pixels
   - Required: 3-10 screenshots

3. **iPhone 5.5"** (iPhone 8 Plus)
   - Resolution: 1242 x 2208 pixels
   - Optional but recommended

4. **iPad Pro 12.9"** (6th generation)
   - Resolution: 2048 x 2732 pixels
   - Required if supporting iPad: 3-10 screenshots

5. **iPad Pro 11"** (4th generation)
   - Resolution: 1668 x 2388 pixels
   - Optional but recommended

### Format Requirements
- **File format:** PNG or JPEG
- **Color space:** RGB
- **No transparency**
- **No rounded corners** (iOS adds automatically)

## Google Play Store Screenshot Requirements

### Required Device Sizes
1. **Phone Screenshots**
   - Minimum: 320px on shortest side
   - Maximum: 3840px on longest side
   - Aspect ratio: 16:9 to 9:16
   - Required: 2-8 screenshots

2. **7-inch Tablet Screenshots**
   - Same size requirements as phone
   - Optional but recommended

3. **10-inch Tablet Screenshots**
   - Same size requirements as phone
   - Optional but recommended

### Format Requirements
- **File format:** PNG or JPEG
- **24-bit RGB** (no alpha channel)
- **Maximum file size:** 8MB per screenshot

## Screenshot Design Guidelines

### Visual Consistency
- **Brand colors:** Use Eidolon's indigo/purple gradient
- **Typography:** Clean, readable fonts
- **Layout:** Consistent spacing and alignment
- **Quality:** High-resolution, crisp images

### Text Overlays
- **Font:** San Francisco (iOS) / Roboto (Android)
- **Size:** Large enough to read on small screens
- **Contrast:** High contrast for readability
- **Language:** English (primary), localize later

### Content Guidelines
- **Real data:** Use realistic but anonymized content
- **Positive messaging:** Focus on benefits and success
- **Clear value:** Each screenshot should show clear value
- **No personal info:** Avoid any real personal data

## Screenshot Testing

### Before Submission
- [ ] Test readability on actual devices
- [ ] Verify text is legible at thumbnail size
- [ ] Check color accuracy on different screens
- [ ] Ensure consistent branding across all screenshots
- [ ] Validate file sizes and formats
- [ ] Test on both light and dark system themes

### A/B Testing Considerations
- **Headline variations** - test different value propositions
- **Feature focus** - emphasize different core features
- **Visual style** - test different design approaches
- **Call-to-action** - test different motivational messages

## Quality Checklist

### Technical Quality
- [ ] **Resolution:** Meets minimum requirements
- [ ] **File size:** Under platform limits
- [ ] **Format:** PNG or JPEG as required
- [ ] **Color space:** RGB, no CMYK
- [ ] **Compression:** Optimized but high quality

### Content Quality
- [ ] **Realistic content:** Believable but not personal
- [ ] **Feature demonstration:** Clear feature visibility
- [ ] **Value communication:** Benefits obvious
- [ ] **Brand consistency:** Matches overall design
- [ ] **Text readability:** Clear at all sizes

### Store Compliance
- [ ] **No misleading content:** Accurate representation
- [ ] **No competitor mentions:** Focus on own features
- [ ] **No inappropriate content:** Family-friendly
- [ ] **No false claims:** Evidence-based statements only
- [ ] **Privacy compliant:** No personal data visible
