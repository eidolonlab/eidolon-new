# Eidolon - Memory Training & Recall

A Progressive Web App for evidence-based memory training using multi-sensory weaving and spaced retrieval techniques.

## 🧠 Features

### Core Memory Training
- **Memory Weaving**: Transform simple seeds into rich, multi-sensory memories
- **Spaced Retrieval**: Evidence-based training with optimal timing
- **Future Scenario Rehearsal**: Practice upcoming events with if-then planning
- **Errorless Learning**: Gentle guidance mode for cognitive accessibility

### Advanced Features
- **Multi-Sensory Cues**: Audio, visual, scent, and location anchors
- **Bridge Back**: Factual verification and quiz system
- **Progress Analytics**: Detailed performance tracking and insights
- **PWA Support**: Install on any device, works offline

## 📊 Evidence-Based Techniques

### Multi-Sensory Memory Weaving
Based on research showing that memories encoded with multiple sensory modalities are more robust and easier to retrieve.

### Spaced Retrieval Training
Implements the spacing effect - memories are strengthened when retrieval practice is distributed over time rather than massed.

### Errorless Learning
Provides gentle guidance to prevent incorrect responses, particularly beneficial for users with cognitive challenges.

### Implementation Intentions (If-Then Planning)
Uses evidence-based goal achievement strategies for future scenario rehearsal.
